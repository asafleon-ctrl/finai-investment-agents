# FinAI – מערכת סוכני AI להמלצות השקעה

פרויקט אקדמי (שיעור 2): ממשק בעברית למערכת של סוכני AI שממליצה על השקעות. זה **סימולטור בכסף מדומה בלבד**. המערכת לא מבצעת עסקאות אמיתיות ואין לה גישה לחשבון בנק.

> ⚠️ **כסף מדומה.** כל הסכומים, העסקאות והתוצאות בפרויקט הם חלק מניסוי. אין כאן ייעוץ השקעות.

## מסגרת הניסוי

| פרמטר | הגדרה |
|---|---|
| הון מדומה | ₪30,000 |
| טווח קצר | ₪20,000: עסקאות תוך־יומיות והחזקות של כמה ימים |
| טווח בינוני | ₪10,000: משך ההחזקה מותאם לזמן שנותר בניסוי |
| שווקים | מניות בישראל ובארה״ב |
| ביצוע | ידני בסימולטור בלבד |
| זמן תגובה | עד שעה כברירת מחדל. אפשר להפעיל במפורש חלון מהיר, והוא מוגבל בזמן |
| סיום | 1.1.2027 (נקודת חיתוך מוצעת: 00:00 שעון ישראל, טעונה אישור) |

**מחוץ לתחום הגרסה הראשונה:** מינוף, שורט, נגזרים, ביצוע אוטומטי, פקודות מותנות ורכישות שלא הגיעו מהמלצות המערכת. המערכת רשאית גם להימנע מהמלצה ולהשאיר את הכסף במזומן.

## הסוכנים

| סוכן | אחריות | תוצר מרכזי |
|---|---|---|
| א׳ | שוק, מניות ונתונים | ממצאים עם מקורות, חותמות זמן ומגבלות |
| ב׳ | חדשות ואירועים | אירועים רלוונטיים, בהפרדה בין עובדה לפרשנות |
| ג׳ | פרופיל, סיכון, זמינות ומשוב | מדיניות אישית, אילוצים ומצב השהיה |
| ד׳ | תכלול, המלצות ומעקב החזקות | אחת משלוש החלטות: להמליץ / להמשיך לעקוב / לפסול |

אישור כרטיס המלצה **אינו** מבצע עסקה. ביצוע מתבצע רק במסך נפרד, אחרי בדיקה מחודשת של ההמלצה.

## ספי סיכון

הירידה נמדדת מההון ההתחלתי, בנפרד לכל היקף:

| היקף | בדיקה (5%) | השהיה (10%) |
|---|---|---|
| התיק הכולל | ₪1,500 | ₪3,000 |
| טווח קצר | ₪1,000 | ₪2,000 |
| טווח בינוני | ₪500 | ₪1,000 |

- **5%:** נפתחת בדיקה מחייבת. כניסות חדשות לא מושהות.
- **10%:** כניסות חדשות מושהות בהיקף שנפגע. התאוששות במחיר לא מבטלת את ההשהיה. חידוש הפעילות דורש החלטה מפורשת ומתועדת.
- הספים אינם תקרת הפסד מובטחת.
