## Brand & Style

This design system delivers an institutional-grade, data-dense wealth management interface crafted for automated algorithmic finance and multi-agent coordination. Designed natively for Right-to-Left (RTL) Hebrew typography and reading flow, the visual language balances high-velocity telemetry with deliberate, sovereign authority.

### Personality & Emotional Tenor
- **Absolute Fiduciary Trust:** Clean mathematical precision, high contrast, and zero novelty noise. Every metric communicates verifiability, institutional safety, and computational rigor.
- **Agentic Clarity:** Multi-agent operations (א׳, ב׳, ג׳, ד׳) demand distinct behavioral states, transparency of rationale, and auditable lineage rather than opaque black-box outputs.
- **Sovereign Composure:** Deep slate-navy foundations paired with strategic financial emerald and cautionary amber evoke the precision of top-tier institutional trading desks.

### Visual Style Direction
The aesthetic fuses **Corporate Modern** with **Technical Precision**:
- Razor-sharp structural alignment with 1px precision dividers.
- Deep, low-reflectance surfaces with subtle luminous highlights for dynamic system metrics.
- High typographic legibility optimized specifically for bidirectional Hebrew (RTL) text alongside Latin mathematical symbols and financial tickers.

## Colors

The palette is engineered around dark-spectrum institutional finance, ensuring endurance during high-frequency monitoring and immediate cognitive processing of mission-critical signals.

### Core Architecture
- **Primary (`#10B981` — Sovereign Emerald):** Reserved for capital growth, positive yield anomalies, active agent execution, and verified mathematical proof checks. Emits targeted luminescence against deep backgrounds.
- **Secondary (`#0F172A` — Deep Slate Navy):** The structural core for cards, grouped telemetry modules, navigation headers, and containment wells. Provides warm-toned contrast without visual exhaustion.
- **Tertiary (`#F59E0B` — Advisory Amber):** Denotes human-in-the-loop warnings, 5% audit triggers, execution holdbacks, and agent drift alerts.
- **Neutral (`#090D16` — Abyss Navy):** Foundational canvas color. Deeper than classic charcoal to produce true contrast for dense tabular datasets.

### Functional System Tones
- **Critical Breached Threshold (`#EF4444` — Sovereign Crimson):** Dedicated exclusively to the 10% safety freeze, circuit breakers, agent disconnections, and negative drawdown.
- **Agent Cluster Hues:**
  - Agent א׳ (Alpha Generation): Cyan Slate (`#06B6D4`)
  - Agent ב׳ (Risk Mitigation): Royal Indigo (`#6366F1`)
  - Agent ג׳ (Liquidity Routing): Emerald Light (`#34D399`)
  - Agent ד׳ (Audit & Verification): Amber Ochre (`#FBBF24`)
- **Text & Stroke Scale:**
  - High-Emphasis Content: `#F8FAFC`
  - Body & Operational Values: `#CBD5E1`
  - Secondary Metadata & Rationale: `#64748B`
  - Subtle Borders & Dividing Rules: `#1E293B`

## Typography

The design system exclusively adopts **Rubik** for both Hebrew and Latin content, utilizing its humanist geometric character, sturdy vertical proportions, and optimized Hebrew diacritic and glyph curves.

### RTL Typography Execution Rules
- **Bidirectional Alignment:** Dashboard layouts strictly align body text, headers, and descriptions to the right (`text-align: right; dir="rtl"`). 
- **Monetary & Numeric Integrity:** Financial values (e.g., `₪30,000` or `+12.4%`) must render with tabular figures (`font-variant-numeric: tabular-nums`). The shekel sign (`₪`) precedes the metric without ambiguous space, anchoring reading consistency.
- **Agent Cluster Labeling:** Identifiers for agent cohorts (א׳, ב׳, ג׳, ד׳) use `label-sm` with medium weights, avoiding faux-bold distension in Hebrew glyphs.
- **Rationale & Analysis Blocks:** Model explainability summaries use `body-md` with strict line-height adherence (20px on 14px type) to maintain readability across dense paragraph scans.

## Layout & Spacing

Layout geometry follows an 8pt operational modular system with a 4pt sub-grid for dense dashboard instruments.

### Fluid Grid Architecture
- **Desktop (1280px+):** 12-column layout with fixed 2rem outer margins and 1.25rem gutters. The navigation dock is pinned rightward (RTL convention), spanning 260px or collapsing to 72px icon-only.
- **Tablet (768px - 1279px):** 8-column layout. Agent control clusters wrap from a horizontal rail into a 2x2 grid matrix.
- **Mobile (<768px):** 4-column layout. High-level metric banners (Virtual Capital: ₪30,000) anchor to the top sticky scroll area. Agent toggles and investment recommendations condense into swipeable or accordion views.

### Directional Spacing Semantics
Padding and margins must never utilize physical `left` and `right`. Implement CSS logical properties exclusively:
- `padding-inline-start` for leading element offsets (e.g., right side in Hebrew).
- `padding-inline-end` for trailing element offsets (e.g., left side in Hebrew).
- `margin-inline-end` between inline badge chips and their accompanying descriptive metadata.

## Elevation & Depth

The system uses flat tonal stacking with micro-borders rather than fuzzy floating drop shadows, preserving sharp readability in dense analytical interfaces.

### Surface Hierarchy (Tonal Layering)
- **Base Canvas (`Level 0` - `#090D16`):** The foundational substrate.
- **Subordinate Wells (`Level 1` - `#0C1322`):** Sunken utility panels, agent audit log backgrounds, inactive track zones.
- **Component Surfaces (`Level 2` - `#0F172A`):** Core investment recommendation cards, top metric displays, telemetry panels. Outlined with a fine 1px stroke of `#1E293B`.
- **Raised & Active States (`Level 3` - `#1E293B`):** Hover states, open recommendation rationale overlays, popover validation inspections. Outlined with `#334155`.

### Ambient Edge Luminance
To indicate live processing without heavy shadows:
- **Active Agent Cards:** A subtle top border gradient (`border-t`) using `rgba(16, 185, 129, 0.4)` fading to transparent slate.
- **Audit Alert Level (5%):** Outlined with `#F59E0B` at 40% opacity, supplemented by an internal glow: `box-shadow: inset 0 0 12px rgba(245, 158, 11, 0.05)`.
- **System Freeze (10%):** Outlined with `#EF4444` with a static 1px perimeter ring.

## Shapes

The design system employs **Soft (`1`)** geometry (0.25rem / 4px base radius) to evoke calibrated technical instrumentation, avoiding excessive roundness that wastes space in high-density data views.

### Geometric Rules
- **Base Controls & Inputs (`rounded` / 4px):** Standard action buttons, availability toggles, text search fields, threshold sliders.
- **Data Cards & Containers (`rounded-lg` / 8px):** Agent status clusters, recommendation dossiers, telemetry tables.
- **Status Badges & Validation Pills (`rounded-full`):** Metric indicators, 30,000 ILS virtual balance tokens, agent group avatars (א׳, ב׳, ג׳, ד׳), and risk threshold labels.

## Components

### 1. Capital & Metric Badges
- **Virtual Balance Pill:** Displays `₪30,000 הון וירטואלי`. Background in `#0F172A` with an active emerald indicator dot (6px) and a 1px border of `#1E293B`. The currency symbol and numerals render bold, tabular, and high-contrast (`#F8FAFC`).
- **Risk Threshold Badges:**
  - *ביקורת (5% Audit):* Styled with amber text (`#F59E0B`), an amber tint background (`rgba(245, 158, 11, 0.1)`), and warning icon positioned inline-start.
  - *הקפאה (10% Freeze):* High-intensity red background (`rgba(239, 68, 68, 0.15)`), red text (`#EF4444`), bold tabular percentage readout.

### 2. Multi-Agent Group Controls (א׳, ב׳, ג׳, ד׳)
- **Status Container:** Grouped card presenting:
  - Agent Hebrew glyph badge (`א׳`, `ב׳`, `ג׳`, `ד׳`) nested in an accented circle.
  - Performance attribution metric (e.g., `+4.2%`).
  - Active execution state label (`פעיל`, `בהמתנה`, `בבדיקה`).
- **Availability Toggle:** Custom RTL toggle switch. 
  - Track: 36px x 20px, `#1E293B` when disabled, `#10B981` when active.
  - Knob: 16px circle, shifting smooth-right when active (RTL orientation: active shifts to the right edge).

### 3. Investment Recommendation Cards
- **Structure:**
  - **Header (RTL):** Asset identifier (e.g., `TA-35 / TASE`), agent signature badge, and algorithmic confidence rating (`94% התאמה`).
  - **Rationale Drawer:** Explanatory text rendered in `body-md` (`#CBD5E1`), strictly detailing multi-factor thesis, valuation deviations, and trigger scenarios.
  - **Sources & Citations:** Micro-tags linking to financial sources (e.g., `דוחות כספיים רבעון 3`, `ספר פקודות זמן-אמת`).
  - **Validation Checks Checklist:** Vertical stacked row of binary conditions (Liquidity, Spread, Macro Volatility) marked with micro green checkmarks (`#10B981`) or amber inspection icons (`#F59E0B`).

### 4. Interactive Buttons & Form Elements
- **Primary Execution Button:** Solid emerald background (`#10B981`), dark slate text (`#090D16`), weight 600. Hover triggers a lightness boost (`#34D399`). Focus ring emits an emerald glow.
- **Secondary / Auditing Action:** Transparent slate with a 1px border (`#334155`), text color `#F8FAFC`.
- **Data Inputs & Filter Dropdowns:** Dark inset background (`#0C1322`), 1px slate border, placeholder text `#64748B`. Hebrew text alignment starts right, chevron icons pin to inline-end (left).
